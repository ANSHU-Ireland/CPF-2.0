# Code of Conduct

## Our standard

Participation in this project is professional. We expect:

- Respectful, direct, and honest technical communication
- Assumption of good faith; critique of ideas, not people
- No harassment, discrimination, or personal attacks of any kind
- Care with confidential material: candidate data, customer names, and
  security findings never appear in issues, commits, or public discussion

## Enforcement

Violations may result in removal from the project. Report concerns privately
to the maintainers.

This project builds hiring technology. The fairness, dignity, and privacy
principles the product enforces for candidates apply equally to how we treat
each other.
